# Home Network Black Box — Phase 0 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** สร้างเครื่องวัดพื้นฐานของ Black Box — probe ping/DNS/Wi-Fi/ARP, เก็บลง SQLite, มี CLI และรันได้จาก VS Code

**Architecture:** แพ็กเกจ `blackbox` แยก probes / store / events / cli; probe ทุกตัวคืน `ProbeResult` แล้วเขียนเป็น batch เดียว; runner เป็น single writer และใช้ `meta` เก็บสถานะรอบล่าสุด

**Tech Stack:** Python 3.14, SQLAlchemy 2.x Core, Alembic, dnspython, pytest, SQLite (WAL)

**Spec:** `black-box/docs/superpowers/specs/2026-11-19-black-box-mvp-design.md`

## Global Constraints

- Windows-first (Windows 10/11), ไม่ต้องสิทธิ์ admin
- SQLite เท่านั้น; SQLAlchemy 2.x Core เท่านั้น (ไม่มี ORM/Session)
- เวลาเก็บเป็น UTC ISO-8601
- read-only ต่อ router; ไม่มี Save/Apply/Reboot
- ไม่ดัก payload; ARP เป็น passive `arp -a` เท่านั้น
- public IP probe default **off**
- target allowlist: gateway, `1.1.1.1`, `8.8.8.8`
- ห้าม hard-code path; ใช้ `--data-dir` หรือ `%APPDATA%\BlackBox`
- ไฟล์หลัก `main.py` ที่ root; รันจาก root ได้โดยไม่ต้องตั้ง `PYTHONPATH`
- interpreter `.venv\Scripts\python.exe`; `PYTHONUTF8=1`
- โค้ด/ชื่อฟังก์ชันภาษาอังกฤษ; ข้อความ CLI ที่ผู้ใช้เห็นเป็นภาษาไทย

## Review Focus

1. **Windows ภาษาไทย/อังกฤษ** — `netsh` และ `arp` ให้ผลคนละ label; parser ต้องอ่านได้ทั้งคู่ (Task 6, 7)
2. **ICMP ถูกบล็อก** — ping ไม่ตอบทั้งหมดต้องเป็น `error_kind='network'` ไม่ใช่ `probe_error` (Task 4)
3. **DNS timeout vs NXDOMAIN** — ต้องแยก `timeout` กับ `network` และไม่รายงาน success เมื่อ rcode ไม่ใช่ NOERROR (Task 5)
4. **เครื่องหลับ/เวลากระโดด** — รอบที่หายไปต้องสร้าง `monitor_gap` ครั้งเดียว ไม่ซ้ำ (Task 10, 12)
5. **หลาย NIC / VPN** — route ที่ metric ต่ำสุดต้องถูกเลือก และบันทึก `interface` (Task 8)

```python
import argparse


def build_parser() -> argparse.ArgumentParser:
    parser = argparse.ArgumentParser(prog="blackbox", description="Home Network Black Box")
    parser.add_argument("--version", action="version", version="0.1.0")
    sub = parser.add_subparsers(dest="command")
    sub.add_parser("probe", help="run probes")
    sub.add_parser("show", help="show recorded data")
    sub.add_parser("db", help="database maintenance")
    return parser


def main(argv: list[str] | None = None) -> int:
    parser = build_parser()
    args = parser.parse_args(argv)
    if args.command is None:
        parser.print_help()
        return 0
    return 0
```

- [ ] **Step 3: Implement `ping.py`**

- Aggregate per target: `value = round(sum(rtts) / len(rtts), 2)`; `loss_pct = round(100 * (sent - recv) / sent, 1)`.
- If `recv == 0`: `ok=False`, `error_kind="network"`, `value=None`.
- Catch `Exception` per target → `ok=False`, `error_kind="probe_error"`.
- `WindowsEchoSender.send`: `IcmpCreateFile`, `IcmpSendEcho`, `IcmpCloseHandle` via `ctypes.windll.iphlpapi`; convert IP with `socket.inet_aton` → `int.from_bytes(..., "little")`; reply buffer `ICMP_ECHO_REPLY` + 64 bytes; status `0` = success; return `round_trip_time` as float.
- Do not import `ctypes.windll` at module import time on non-Windows; guard in `__init__`.

- `run_forever`: `while True: try run_cycle(now); except Exception as exc: print(...); sleep(config.base_interval_s)`.
- `recent_events` convenience method delegating to store.
- On first run, `last_cycle=None` → no gap.
